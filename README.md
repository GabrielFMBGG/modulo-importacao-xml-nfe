# Módulo de Importação de XML de NF-e

## Objetivo do repositório

Este repositório reúne a documentação do **Módulo de Importação de XML de NF-e**, responsável por receber arquivos XML de Notas Fiscais Eletrônicas, validá-los, extrair seus dados e disponibilizá-los para uso no sistema.

O repositório contém a **EAP (Estrutura Analítica do Projeto)** do módulo, organizada em 3 níveis, com as entregas (substantivos) necessárias para a sua construção. A EAP está no arquivo [`EAP.md`](./EAP.md).
